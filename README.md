# IskInSkills

A collection of skills for Claude by **AronHopeless**.

## Skills

| Skill | Description | Languages | Docs |
|---|---|---|---|
| [Decision Drill](decision-drill/) | Clarifies and details any project (an app, a thesis, a research study) through a long series of narrow questions with ready-made answer options. Keeps a register of decisions, tracks conflicts and produces a Word report. | EN, RU | [English](decision-drill/README.md) · [Русский](decision-drill/README.ru.md) |

## Installation

Each skill is a folder with a `SKILL.md` file inside.

- **Claude (web and app):** download the repository (**Code → Download ZIP**), put the folder of the skill you need into its own zip archive and upload it in the Skills section of the settings.
- **Claude Code:** copy the skill folder to `~/.claude/skills/`.

See each skill's README for details.
